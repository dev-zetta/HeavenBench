Sky runtime assets
==================

These textures are copied into `heaven/sky/` by HeavenBench's
`--pack-assets` mode. Runtime code resolves only those packaged copies through
the configured data root; it does not search the source repository.

The files originated in Google Filament's web example assets:

- `moon_disk.png`
- `moon_normal.png`
- `milkyway.png`
