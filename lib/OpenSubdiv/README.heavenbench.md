This directory contains the unmodified CPU Far, Sdc and Vtr subset of Pixar OpenSubdiv v3_6_1 (version 30601), plus its version header, LICENSE.txt and NOTICE.txt. The public source archive SHA-256 is `e9d99a480d80e999667643747c76eb0138d36c418fc154fd71b4bd65be103d52`. No Osd device backend, graphics library, examples or tools are included.

The bounded displacement builder needs the native Loop and Gregory triangle construction around extraordinary vertices and protected features. Replacing these domains with independent affine patches would change the validated target and its joins. Application-side exact Gregory derivatives include the rational product rule without changing upstream source.

`cmake/HeavenOpenSubdiv.cmake` builds this subset independently of the renderer. The dependency is licensed under Apache 2.0 with Pixar’s modified trademark clause; retain LICENSE.txt and NOTICE.txt in source and redistributed notices.
